# 顧客マスタ データ仕様メモ

## 概要
小売チェーンの会員マスタを模した合成データ。
分析・画面モック・テストデータ用途を想定。

## 各列の業務ルール

### member_id
- `M` + 7桁のゼロ埋め連番。重複不可。

### gender
- `1`=男性, `2`=女性, `9`=不明。
- 構成比は男性:女性:不明 ≒ 45:50:5 を想定。

### age
- 0〜110。ただし会員は概ね 15〜85 歳に集中。
- 平均は 40 歳前後。

### prefecture_code
- 47都道府県。`01`〜`47` の2桁文字列。
- 東京(13)、大阪(27)、神奈川(14)、愛知(23)、福岡(40)、北海道(01)、埼玉(11)、千葉(12)、兵庫(28) が上位。

### join_date / leave_date
- `join_date` は 2010-01-01 〜 2025-12-31。
- `leave_date` は会員のうち約 15% に設定される。それ以外は null（在籍中）。
- `leave_date` は `join_date` 以降である必要がある。

### member_rank
- `BRONZE`, `SILVER`, `GOLD`, `PLATINUM`。
- 構成比は概ね BRONZE:SILVER:GOLD:PLATINUM = 45:30:18:7。

### annual_spend
- 直近1年の購入合計（円）。0〜3,000,000。
- 会員ランクと相関があり、PLATINUM が高く、BRONZE が低い。
- 年齢ともゆるい正の相関があり、25〜65 歳がボリュームゾーン。

### has_spouse
- `0`=配偶者なし, `1`=配偶者あり。
- 18歳未満は必ず `0`。
- 配偶者あり比率は年齢が上がるほど上昇する。

### email_optin
- メール許諾。0/1 のフラグ。全体の約 70% が 1。

### registration_channel
- `WEB`, `STORE`, `APP`, `PHONE`。
- 構成比は概ね WEB:STORE:APP:PHONE = 40:25:25:10。
